# PIXEL - Art Gallery Website

PIXEL is a simple art gallery website that we made as a college project. It keeps artists, artworks and exhibitions in one place, so they are easy to find and easy to browse.

**Live website:** https://kron0975.github.io/PIXEL/

## Pages

- **Dashboard (`index.html`)** - the home page with a featured painting and exhibitions
- **Artists (`artists.html`)** - details of the artists
- **Artworks (`artworks.html`)** - cards with the picture, title, artist, year and status
- **Exhibitions (`exhibitions.html`)** - information about the exhibitions
- **Gallery (`gallery.html`)** - about the gallery, featured artworks, timings and contact

## Features

- Same navigation bar on every page
- Artwork cards shown in a neat grid
- Clean and simple design


## Built With

- HTML
- CSS (Grid, Flexbox and media queries)

## How to Run

1. Download or clone this repository
2. Open `index.html` in any browser

No installation is needed.
